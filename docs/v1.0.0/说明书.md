# 禾影千寻使用说明书

## 一、首页

![img.png](../img/home.png)

禾影千寻是一款面向智慧农业领域打造的 AI 智能分析平台，整体采用简洁现代的绿色科技风设计，围绕"大模型 + 知识图谱 + 视觉识别"三大核心技术展开。平台致力于为农业场景提供智能化分析、知识问答与病虫害识别等服务，助力智慧农业数字化建设。

首页采用模块化布局设计，主要包含"主页、Agent、图谱、博客"四个功能页面入口，通过图文结合的方式展示平台核心能力与应用场景。页面整体结构清晰，视觉风格统一，能够直观体现平台的技术特点与产品定位。

### 平台核心功能

- **Agent 智能体编排**
  基于大模型与 LangGraph 工作流，实现多步骤推理、工具调用与智能任务协同处理，提高复杂农业问题的分析效率。平台内置多种专用 Agent，涵盖通用问答、深度调查、病虫害识别等场景。

- **YOLO 病虫害目标检测**
  利用计算机视觉与 YOLO 目标检测技术，对农作物病虫害进行识别与定位，辅助农业生产监测与管理。用户上传作物图片后，系统自动检测并标注病虫害区域，返回识别结果与置信度。

- **结构化知识图谱**
  通过知识图谱技术（Neo4j + LightRAG）构建农业领域实体关系网络，实现农业知识关联分析与智能检索，提升知识管理能力。支持可视化的图谱交互与节点详情查看。

- **AI 智能问诊**
  结合农业知识库与大模型能力，为用户提供智能问答、病害诊断及农业种植建议等服务。支持上传图片进行病虫害识别，结合天气数据与知识库给出综合防治方案。

- **智能分析报告**
  系统能够自动生成结构化分析报告，对识别结果与农业数据进行总结与分析，辅助用户进行科学决策。支持导出 PDF 格式报告。

此外，平台还提供博客模块，用于展示农业 AI 相关文章、技术分享与平台动态，增强系统的信息展示与内容扩展能力。


## 二、登录注册

### 登录
- 首次运行系统时，会进入初始化页面，需要创建超级管理员账号
- 正常登录使用用户名或手机号 + 密码
- 支持"记住我"功能

- 登录成功后根据角色跳转：管理员进入 Agent 管理页，普通用户进入默认 Agent

- 使用邮箱注册，需要先获取邮箱验证码（60 秒冷却时间）
- 用户名支持中文、字母、数字，长度 2-20 位
- 密码长度 6 位以上


## 三、AI 对话

![chat.png](../img/chat.png)

平台提供两种对话方式：**千寻问农** 和 **千寻有方**。

### 千寻问农（通用问答 Agent）

千寻问农是通用聊天 Agent，具备以下能力：

| 功能 | 说明 |
|------|------|
| 病害识别 | 上传作物图片，自动调用 YOLO 目标检测进行病虫害识别 |
| 药品查询 | 查询农业药品信息，用法用量、注意事项等 |
| 天气查询 | 根据用户所在地查询实时天气与预报 |
| 知识库检索 | 基于 RAG 技术检索农业知识库 |
| 联网搜索 | 通过 Tavily 搜索引擎获取最新网络信息 |
| 知识图谱查询 | 查询 Neo4j 知识图谱中的实体关系 |
| 计算器 | 数学表达式求值 |
| 图像生成 | AI 生成农业相关图片 |
| 附近用户 | 根据地理位置查找附近农户 |

**病害识别流程**：用户上传作物图片 → 自动调用 YOLO 目标检测 → 识别病虫害并标注图片（含置信度） → 查询当地天气 → 检索知识库获取病症与解决方案 → 返回包含病症、防治措施、推荐用药的综合报告。推荐用药会根据当前季节和天气情况给出具体指导。

![wen.png](../img/wen.png)

### 千寻有方（深度调查 Agent）

千寻有方是深度调查 Agent，能够自主制定调查计划，创建子 Agent 进行多维度调查，最终生成完整的分析报告。适用于需要深度分析的复杂农业问题。

### Agent 配置

管理员可为每个 Agent 配置以下参数：

- **模型选择**：选择底层的对话模型
- **系统提示词**：定义 Agent 的行为与人格
- **工具配置**：启用/禁用工具列表（如病害识别、天气查询、知识库等）
- **知识库关联**：绑定需要检索的知识库
- **配置模板**：可创建多个配置模板，在不同场景间快速切换，支持设置默认模板

### 对话管理

- 支持多轮对话，自动保存对话历史
- 可创建多个对话线程，支持切换、重命名、删除
- 消息支持点赞/点踩反馈
- 支持流式输出（SSE），实时显示回复内容
- 附件上传：支持图片、文件等多种格式
- 对话可导出为 HTML 文件

## 五、知识图谱

![tupu.png](../img/tupu.png)

知识图谱模块基于 Neo4j 图数据库构建，展示农业领域实体之间的关联关系。

**功能说明**：
- 右上角可选择要展示的知识库（支持 Neo4j 和 LightRAG 两种图谱类型）
- 图谱连接状态指示：绿色=已连接，灰色=未连接，闪烁=加载中
- 节点交互：点击选中节点显示详情信息，拖动调整图谱布局
- 边交互：点击连线查看实体关系详情
- 搜索功能：按名称搜索实体节点（输入 `*` 查看全部节点）
- 采样控制：可调节加载的节点数量
- 数据导出：支持将图谱数据导出为 JSON 文件

**管理员功能**：
- 导入实体：上传 JSONL 文件向图库添加实体
- 索引节点：为未索引的 Neo4j 节点添加嵌入向量


## 六、知识库管理

![zsk.png](../img/zsk.png)

### 知识库类型

平台支持多种知识库后端：

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **LightRAG** | 基于知识图谱的 RAG，能构建实体关系网络，支持图谱展示 | 复杂知识关联分析 |
| **Milvus** | 向量数据库，高性能相似度检索 | 大规模文档检索 |
| **FAISS** | 本地向量索引，轻量高效 | 中小规模本地部署 |
| **Qdrant** | 向量搜索引擎 | 高性能检索场景 |

推荐使用 **LightRAG**，它不仅能进行语义检索，还能自动构建实体关系图谱，实现知识间的关联分析。纯向量数据库无法直接构建图谱，展示效果不如 LightRAG 直观。

### 创建知识库
- 选择知识库类型，填写名称和描述
- 选择嵌入模型（Embedding Model）
- LightRAG 类型还需选择语言和 LLM 模型
- 配置共享权限（指定可访问的用户）

### 知识库详情

![zsk.png](../img/zsk.png)

进入知识库后可进行以下操作：

**文件管理**：
- 上传文件：支持 PDF、Word、Excel、PPT、TXT、Markdown、HTML、JSON、CSV、图片等多种格式
- URL 内容抓取：从指定 URL 获取内容入库
- 文件夹上传：支持 zip 压缩包批量上传
- 文件夹分类管理：创建文件夹组织文件
- 文件在线预览：查看解析后的文档内容
- 批量解析和索引：一键处理待处理的文件

**知识图谱**（LightRAG 类型）：
- 可视化展示知识库中实体的关系网络
- 支持交互式浏览和搜索

**检索测试**：
- 输入查询语句测试检索效果
- 自动生成示例问题
- 调整检索参数（rerank、top_k 等）

**思维导图**：
- AI 自动从知识库文件生成知识思维导图
- 基于 Markmap 渲染，支持交互式展开/折叠

**RAG 评估**（Milvus 类型）：
- 上传或自动生成评测基准数据集
- 运行 RAG 评估并查看详细指标
- 查看评测历史记录

### 文件处理流程

上传的文件需要经过两个阶段才能被 Agent 检索到：

1. **解析（Parse）**：将原始文件转换为 Markdown 格式文本。不同类型文件使用不同的解析引擎：
   - Office 文件（docx/xlsx/pptx）：使用 Docling 转换为 Markdown，并提取嵌入图片上传至 MinIO
   - PDF/图片：可使用 OCR 引擎解析（详见下文）
   - 纯文本/Markdown：直接读取
   - HTML：通过 BeautifulSoup + markdownify 转换
   - CSV/Excel：按行转换为 Markdown 表格
   - JSON：格式化为 Markdown 代码块

2. **索引（Index）**：将解析后的文本向量化，存入向量数据库，使 Agent 能够检索

### 知识库导出

支持导出为 CSV、XLSX、Markdown、TXT 等格式。

### OCR 文档解析引擎

平台支持多种 OCR 引擎用于 PDF 和图片的文本提取：

| OCR 引擎 | 类型 | 特点 |
|----------|------|------|
| **RapidOCR (ONNX)** | 本地离线 | 基于 PP-OCRv4 模型，无需外部服务，纯 CPU 可运行 |
| **MinerU** | 本地服务 | 基于视觉语言模型的高精度解析，支持版面分析、表格和公式识别（需 GPU） |
| **MinerU 官方** | 云端 API | MinerU.net SaaS 服务，通过 API Key 调用 |
| **PaddleX (PP-StructureV3)** | 本地服务 | 版面分析引擎，支持表格和公式识别（需 GPU） |
| **DeepSeek OCR** | 云端 API | 通过 SiliconFlow 调用 DeepSeek-OCR 视觉语言模型 |

可在系统设置中配置默认 OCR 引擎，也可以在文件上传时指定使用的引擎。

## 九、Webhook 推送管理

![setwebhook.png](../img/setwebhook.png)

平台提供 Webhook 推送功能，支持外部系统通过 API 向用户推送消息。

### 推送源管理
- 创建推送源：填写名称、提示词（控制消息生成风格）
- 创建成功后系统自动生成唯一推送 Token
- 支持启用/停用推送源

### 推送方式

**外部推送**：
外部系统通过 `POST /api/webhook/receive/{token}` 发送请求，请求体中的消息会经过 Agent（推送消息助手）处理后推送给用户。

**快速推送（内部）**：
管理员可直接通过管理界面发送消息，无需外部调用，支持：
- 选择推送源
- 填写消息内容
- 设置推送过滤条件（作物类型、地理位置经纬度与半径等）
- 实时查看推送结果

### 推送渠道
- **平台对话**：推送到用户最近的 Agent 对话中
- **QQ 邮箱**：发送到用户绑定的 QQ 邮箱

## 十二、系统设置（后台管理）

![setting.png](../img/setting.png)

系统设置分为四个功能标签页，不同角色可见范围不同：

### 1. 基础设置（仅超级管理员）

- **对话模型**：选择默认的聊天模型
- **快速模型**：选择快速响应模型
- **嵌入模型**：选择文本嵌入模型
- **Reranker 模型**：选择重排序模型
- **内容审查**：启用/禁用 LLM 内容审查，配置审查模型

### 2. 模型配置（仅超级管理员）

- **自定义提供商**：添加和管理自定义 LLM 提供商（ID、名称、地址、API Key、默认模型、可用模型列表）
- **连接测试**：测试提供商连接是否正常
- **内置提供商**：查看内置 LLM 提供商（百炼、DeepSeek、豆包、ModelScope、OpenAI、OpenRouter、SiliconCloud、Together、智谱等）

### 3. 用户管理（管理员以上）

- **创建用户**：自动生成用户 ID，设置角色（超级管理员/管理员/普通用户）、密码、邮箱
- **编辑用户**：修改用户名、手机号、角色
- **删除用户**：软删除（匿名化处理并释放手机号）
- **用户名验证**：实时检测用户名可用性

### 4. 邮箱设置（仅超级管理员）

- 配置 SMTP 服务器（主机、端口、用户名、密码、发件人名称、发件人地址）
- 测试邮件发送

## 十六、AI Agent 架构说明

### 内置 Agent

| Agent 名称 | 类型 | 说明 |
|------------|------|------|
| 千寻问农 | ChatbotAgent | 通用农业问答 Agent，集成多种工具 |

### 工具系统

Agent 通过工具（Tool）与外部系统交互。当前可用的工具包括：

| 工具 | 功能 |
|------|------|
| 知识库检索 | RAG 检索，从关联知识库获取信息 |

3. **数据库**：PostgreSQL 和 Neo4j 建议使用外部实例或定期备份数据卷
4. **环境变量**：妥善保管 API Key 和密码，勿提交到版本控制
5. **资源限制**：在 docker-compose.yml 中为各服务配置资源限制

## 附录：常见问题

**Q: 如何切换 AI 模型？**
A: 管理员可在 Agent 配置中选择模型，或在"系统设置 → 模型配置"中添加自定义模型提供商。

**Q: 上传文件支持哪些格式？**
A: 支持 PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（pptx）、TXT、Markdown、HTML、JSON、CSV、图片（jpg/png/bmp/tiff）等格式，系统会自动解析处理。

**Q: 知识库文件如何变成可检索？**
A: 上传文件后需要经过"解析（Parse）→ 索引（Index）"两个阶段，完成后即可在对话中检索。可在文件列表中查看处理状态。

**Q: 如何将平台集成到外部系统？**
A: 可使用 Webhook 推送功能，通过 `POST /api/webhook/receive/{token}` 接口将消息推送到平台用户。

**Q: 忘记密码怎么办？**
A: 当前版本暂未开放自助找回密码功能，请联系管理员重置密码。

**Q: 为什么 OCR 解析失败？**
A: 检查对应 OCR 服务是否正常运行。RapidOCR 是本地离线引擎无需额外服务；MinerU 和 PaddleX 需要对应的 Docker 容器运行正常。

**Q: 如何配置邮箱？**
A: 超级管理员可在"系统设置 → 邮箱设置"中配置 SMTP 信息，或直接在 `.env` 文件中配置 `SMTP_*` 环境变量。

**Q: 如何开启内容审查？**
A: 超级管理员在"系统设置 → 基础设置"中启用"内容审查"开关，并配置审查使用的模型。
