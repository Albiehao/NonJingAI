# 禾影千寻使用说明书

## 一、首页

![img.png](../img/home.png)

禾影千寻是一款面向智慧农业领域打造的 AI 智能分析平台，整体采用简洁现代的绿色科技风设计，围绕“大模型 + 知识图谱 + 视觉识别”三大核心技术展开。平台致力于为农业场景提供智能化分析、知识问答与病虫害识别等服务，助力智慧农业数字化建设。

首页采用模块化布局设计，主要包含“主页、Agent、图谱、博客”四个功能页面，通过图文结合的方式展示平台核心能力与应用场景。页面整体结构清晰，视觉风格统一，能够直观体现平台的技术特点与产品定位。

平台核心功能包括：

* **Agent 智能体编排**
  基于大模型与 LangGraph 工作流，实现多步骤推理、工具调用与智能任务协同处理，提高复杂农业问题的分析效率。

* **YOLO 病虫害目标检测**
  利用计算机视觉与 YOLO 目标检测技术，对农作物病虫害进行识别与定位，辅助农业生产监测与管理。

* **结构化知识图谱**
  通过知识图谱技术构建农业领域实体关系网络，实现农业知识关联分析与智能检索，提升知识管理能力。

* **AI 智能问诊**
  结合农业知识库与大模型能力，为用户提供智能问答、病害诊断及农业种植建议等服务。

* **智能分析报告**
  系统能够自动生成结构化分析报告，对识别结果与农业数据进行总结与分析，辅助用户进行科学决策。

此外，平台还提供博客模块，用于展示农业 AI 相关文章、技术分享与平台动态，增强系统的信息展示与内容扩展能力。

## 三、 ai对话
![img.png](../img/chat.png)
提供2种对话方式
- 千寻问农
- 千寻有方

千寻问农是普通聊天agent,拥有以下功能
- 病害识别
- 药品查询
- 天气查询
- 知识库检索
- 联网搜索

当用户上传图片时，agent自动会调用目标检测工具来进行图像识别，并且将识别出来的病害，置信度，画完框后的图片返回给agent,并且通过天气工具查询用户农田的天气状况，
agent通过调用知识库来查询具体病症以及解决方案，给用户明确的病症+措施+推荐用药。
推荐用药也会根据当前的季节，最近的天气情况来给出具体的指导。
![img.png](../img/wen.png)

千寻有方是深度调查agent，会自主调查
会创建一个完整的调查计划，创建子agent去自主调查并且生成完整的报告
